# Seethe

> 看见我 · 了解我 · 走近我

极简黑白灰低饱和度数字名片与档案库。

## 页面结构

- **01 // 看见我**：Seethe 封面名片，恰如一只飞鸟，错落飞羽与极简叙事。
- **02 // 了解我**：About me 个人信息档案。
- **03 // 走近我**：Drowning us 外链文档索引（话术、你对我的夸赞、卡类、须知）。
